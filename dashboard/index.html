⚡ Zero-Allocation Bitmask Undo Trail

Domains are stored as integer bitmasks. Variable assignments push pruned masks to an undo trail stack. Backtracking simply un-masks via bitwise OR, achieving over 100,000 node visits per second on a single CPU core.

🛡️ Ground-Truth Verifier & OR-Tools Sanity

Every solution returned by the solver is validated by an independent assertion checker against all domain bounds, binary tables, and AllDifferent groups. Google OR-Tools CP-SAT is utilized exclusively as an external test-suite oracle.

🔒 Strict Instance-Level Partitioning

Data splits are partitioned strictly by problem instance hash (0% search-node leakage). Machine learning feature extractors evaluate dynamic search states with zero access to planted solutions.
